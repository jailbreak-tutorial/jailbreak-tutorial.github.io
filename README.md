# Jailbreaking LLMs and Agentic Systems: Attacks, Defenses, and Evaluations

This is the website for the ICML 2024 tutorial on Jailbreaking LLMs and Agentic Systems.

## Website Setup

This website is hosted on GitHub Pages at [jailbreak-tutorial.github.io](https://jailbreak-tutorial.github.io).

### Local Development

To run the website locally:

1. Clone this repository
2. Open `index.html` in your web browser

### Adding New Content

To add new content to the website:

1. Create new HTML files in the root directory
2. Link to them from the main `index.html` file
3. Push changes to the main branch
